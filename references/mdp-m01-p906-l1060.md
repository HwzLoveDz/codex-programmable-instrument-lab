# MINIWARE MDP-M01、P906 与 L1060 联调边界

本页记录官方资料审阅、2026-09-23 的临时脚本轻载联调、2026-09-24 新适配器的低功率 P906+L1060 闭环，以及仍未验证的能力。新适配器已通过假串口离线测试和一次真实 5 V/0.1 A CC 轻载功能检查；这不构成全量程或准确度验收。

## 控制链路与状态解释

- MDP-M01 主机与电脑使用 USB CDC 串口，官方上位机源码使用 115200、8 数据位、无校验、1 停止位。
- M01 状态帧将最多六个槽位合并上报；通道索引是零起始的协议字段，操作员看到的 UI 通道号是一开始加一。每次连接后都应从状态帧识别机器类型和在线状态，不能假定 CH1/CH2 永远装着同一设备。
- 官方上位机源码中的机器类型 `2` 为 P906、`3` 为 L1060。P906 的模式值与 L1060 不同：L1060 的 `0/1/2/3` 分别表示 CC/CV/CR/CP。对 L1060，运行／输入使能状态是独立字段；模式仍显示 CC 时不代表输入已开启。
- 上位机源码的电压和电流设定以 mV、mA 小端字段发送；官方源码对每个设定帧按约 30 ms 间隔发送两次。输出切换使用独立帧。帧已写入主机 USB 串口不代表无线侧模块已执行。
- 官方源码没有为输出状态切换定义可等待的逐命令 ACK。每个设定或输出切换后应读取新的 M01 状态帧，检查 online、错误／锁定标志、设定值及独立输出位；不符合预期或超时后停止，不盲目重发输出 ON/OFF。模拟实际值与状态位可能不同步，端子电压达到目标或归零须由独立仪表按有界稳定判据确认。确认持续时可读后续新状态，但不要重放未知是否已执行的写入。
- 一台 M01 使用一个串口控制者和一个受管连接覆盖完整测试阶段；不要每条设置后关闭串口再重新连接，也不要让 PC 上位机、前面板和自建程序同时控制而相互覆盖。

## 受限适配器：`scripts/mdp_m01.py`

该程序将协议封装为只允许少数操作的 Python API 和命令行会话，不提供任意二进制帧发送。需要 Python 3.10+ 与 `pyserial`。`status` 是一次只读状态快照；`session` 是前台 JSONL 会话，覆盖基线、人工确认、设置、阶段操作和收尾，只在 `end` 后断开。

```text
python -m pip install pyserial
python scripts/mdp_m01.py status
python scripts/mdp_m01.py --port <当前 MDP-M01 串口> session
```

会话从 `status` 返回值找出当前在线设备及通道号。映射随状态动态识别，不将示例 CH1/CH2 固定为 P906/L1060。允许的 JSON 操作：

```json
{"op":"status"}
{"op":"arm","max_voltage_v":5,"max_current_a":0.3,"max_power_w":1.5,"confirm_wiring":true}
{"op":"set_p906","channel":1,"voltage_v":5,"current_limit_a":0.3}
{"op":"set_l1060_cc","channel":2,"current_a":0.1}
{"op":"output_on","channel":2,"confirm_energy":true}
{"op":"output_off","channel":2}
{"op":"end"}
```

保护和支持范围：

- `arm` 必须在操作员确认实际接线、极性、负载、限值及停止条件后执行，并要求全部在线设备输出位为 OFF。它是会话内的软件操作包络，不会检测物理接线或替代器件额定值核对。
- P906 仅开放同时设电压和限流；只能在其输出 OFF 时设置，且不因设置命令自动上电。所接受数值受本次 armed 包络约束，初版实现对 P906 的硬编码软件范围为 30 V、10 A、300 W。
- L1060 只允许在其已经处于 CC 且输入 OFF 时设置电流，不切换 CC/CV/CR/CP 模式。因为尚未完成完整实机和各固件适用范围验证，初版 L1060 CC 设定额外受 1 A 软件上限约束；这不是产品额定值声明。
- 每条 `output_on` 要求 `confirm_energy:true` 且设定值在包络内。OFF 不需要 armed，但仍是单次发送并等待状态回读。协议没有逐命令 ACK，输出开关绝不自动重发。
- `end` 只再读一次状态然后释放 USB，不自动关闭输出，也不承诺清理成功。应在结束前显式关闭相关输出并确认 OFF；若 OFF 超时，停下并让操作者检查实物，再以新的只读状态请求确认。
- 断开或异常不会自动改写输出位、设置值或恢复基线。不要同时运行 MINIWARE PC 上位机、前面板操作与此脚本。
- 当前实现通过离线假串口测试验证帧解析、设备映射、设定回读、输出确认、失败不重发和会话连接生命周期；另于 2026-09-24 实机识别 P906/L1060，验证 P906 设定、L1060 CC 设定、两路输出切换回读和外部电压变化。该轮只覆盖 5 V / 0.3 A 电源限流与 0.1 A CC 负载，不证明额定范围、准确度或其他负载模式。

## 2026-09-23 实机探索记录

接线由操作者确认：P906 输出接 L1060 输入，FLUKE 8845A 前面板 HI/LO 并联在负载输入端；无其他负载。测试使用 P906 5.000 V、0.300 A 限流，L1060 CC 0.100 A（约 0.5 W），8845A 固定 10 V DC 档，每阶段 3 次读数。没有事先约定准确度验收限值，因此不判定合格／失败。

| 阶段 | 状态 | FLUKE 8845A 均值 |
|---|---|---:|
| 基线 | P906 OFF，L1060 OFF | 0.000135 V |
| 电源空载 | P906 ON，5.000 V / 0.300 A，L1060 OFF | 5.006109 V |
| 轻载 | P906 ON，L1060 CC 0.100 A | 5.001783 V |

空载到轻载的观测变化为 −4.326 mV。轻载阶段的 M01 状态帧约报 P906 5.012 V / 0.104 A、L1060 4.938 V / 0.099 A；与并联 Fluke 约 5.002 V 的 L1060 电压读数明显不一致。数据不是严格同时采样，测量点／内部遥测差异尚未调查；不可自行归因于线损补偿、校准或任一台仪器精度。

Fluke `*IDN?` 在新建连接后第一次遭连接重置；仅在未发生任何设置写入和测量之前执行了一次明确的一次性身份重试，之后同一有效 LAN Socket 跨三个阶段保持使用。实验结束时 Fluke `SYST:LOC` 和 `*OPC?` 有返回，Socket 已关闭。示波器当时未接入，因此没有示波器连接问题的证据。

自动收尾时，L1060 OFF 请求后的状态得到确认，但 P906 的远程 OFF 请求没有得到确认；测试标记为清理未验证，没有重复发送 P906 OFF。操作者随后报告已手动关掉 P906，之后新的 M01 只读状态读取确认 P906/L1060 输出位均 OFF，测量值约为 0.019 V / 0.008 V。这里同时保留自动收尾失败和后续人工处置两条事实，不能把它改写为自动安全关闭成功。

## 2026-09-24 新适配器实机核查

在操作员确认同一安全接线后，新适配器在持久 COM26 会话中识别 P906 CH1 和 L1060 CH2，确认均为 OFF，并对 P906 只发送一次 ON 和一次 OFF。FLUKE 持久 LAN 会话观测：ON 请求后 2.51 s 的样本仍接近 0 V，2.79 s 的样本为 5.006043 V；M01 约 2.97 s 才回报 ON 位。这个区间只描述一次端到端观测，不是固定延时或纯无线延时。OFF 后约 0.75 s 状态位变为 OFF，但外部端子在 28.38 s 后仍有 0.378548 V，约 5 分 55 秒后仍有 0.085906 V。M01 的 P906 电压字段与外部读数不同步。详见未公开的本地原始记录 `runs/20260924-123727_mdp-p906-command-latency/`；OFF 不能代替零伏判定。

同日较早一轮轻载计划在启用 L1060 前停止。只读状态曾显示 L1060 在线、P906 离线／未配置，未发送输出指令。独立 FLUKE 测得负载输入端 51、48、48 µV；M01 的 L1060 `input_voltage_v` 却报约 5.21–5.23 V，该字段含义／测点未核清，不能替代端子电压。随后操作员恢复 P906 在线，以下一轮才完成实测。这说明每次闭环都必须重新确认模块在线和通道映射。

## 2026-09-24 新适配器低功率闭环

操作员确认接线未变：P906 OUT 接 L1060 IN，FLUKE 前面板 HI/LO 并联在 L1060 输入端，无其他负载。适配器从 COM26 动态识别 CH1=P906、CH2=L1060；两者在线且无错误／锁定，起始输出位 OFF。FLUKE 8845A 前端 DCV 10 V、NPLC 10、math OFF，以同一持久 LAN 会话采集各阶段。安全包络为 5 V、0.3 A、1.5 W；P906 设 5.000 V / 0.300 A，L1060 为 CC 0.100 A（其既有电压预置显示 9 V）。

| 阶段 | M01 状态／读数 | FLUKE 8845A 端电压均值（5 次） |
|---|---|---:|
| 基线，两路 OFF | P906/L1060 在线、OFF | 0.000206 V（3 次） |
| P906 ON，L1060 OFF | P906 ON 回读，L1060 OFF | 5.005994 V |
| 两路 ON，L1060 CC 0.100 A | 后续 M01 帧：P906 0.107 A；L1060 0.099 A，约 0.489 W，无错误／锁定 | 5.001688 V |
| 两路 OFF 后约 20 s | 两路 OFF 回读 | 0.003111 V（5 次）；紧接 OFF 的早期读数曾均值 1.696102 V 并持续下降 |

空载到加载的外部电压均值变化为 −4.306 mV。紧随加载采样的 M01 状态帧报 L1060 端电压 4.940 V，而相邻 FLUKE 阶段均值为 5.001688 V，相差约 61.7 mV；采样先后不同，差异原因未明。L1060 刚启用后的首个状态帧仍报 0 A，后续状态帧才报 0.099 A。结果支持适配器完成低功率设定、启停和状态回读，也观察到负载接入时电压变化；电流由 M01 遥测回读，未用独立电流表验证。没有预先定义电源精度验收限值，因此不判 pass/fail。M01 关机后的模拟电压字段短时仍接近 5 V，独立 FLUKE 则观测到端子放电；OFF 位不能代表端子已经归零。

FLUKE 和 M01 会话都跨越整个实验阶段保持连接，最终在两路 OFF 回读后正常结束；FLUKE 处理了本地操作恢复并关闭 Socket。完整采样及仪表配置保存在本地忽略目录 `runs/20260924-132448_mdp-l1060-adapter-validation/`。

## 仍待实机验证的事项

1. 其他 L1060 模式、更高电流／功率及其他 P906 工作点仍未实测，不把 5 V/0.1 A CC 结果外推。
2. 另外验证超时、短写、控制器断开和接收错帧的实际行为。超时表示状态未知，不自动重试。
3. 将 MDP 与独立 FLUKE／示波器测量当作不同测量链，记录实际测点、接线及采样先后。内部遥测与外部仪表不一致时报告差异并保留证据，不选取一个读数掩盖另一个。
